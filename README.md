# Stay J Men

남성을 위한 모바일 퍼스널 스타일 어드바이저 파일럿입니다.

## 파일럿 화면

- 사진 두 장을 이용한 3단계 온보딩 시뮬레이션
- MY: 퍼스널컬러, 골격, 피부, 얼굴형과 관리 주기
- TODAY: 오늘 할 일 하나, 의상, 헤어, 그루밍, 포인트 아이템
- ASK: 빠른 SOS 4종과 자유 질문
- 의상 4단계와 헤어 단계별 따라하기
- 전체 진단 리포트

현재 사진 분석과 추천은 화면 흐름 검증용 목데이터입니다. Supabase, 실제 AI 분석, 날씨·예약 API는 아직 연결하지 않았습니다.

## 실행

```bash
npm install
npm run dev
```

## 검증
